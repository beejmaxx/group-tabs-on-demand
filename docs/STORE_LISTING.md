# Chrome Web Store listing copy

## Short description

Group tabs by domain on demand with one click—never automatically.

## Detailed description

Group Tabs on Demand organizes the current Chrome window by website domain
only when you ask it to.

Click the toolbar button or use Command+Shift+K on macOS (Ctrl+Shift+K on other
platforms) to rebuild your tab groups. Subdomains such as mail.google.com and
docs.google.com are placed together under a short label such as GOOGLE.

Each run cleans up existing tab groups first, so mixed-domain and stale groups
are repaired automatically. Pinned tabs and domains with only one tab remain
ungrouped.

The extension never reacts automatically when tabs open or navigate. It has no
analytics, telemetry, ads, accounts, or remote services. All processing stays
inside Chrome.

## Single purpose

Organize tabs in the current browser window into Chrome tab groups based on
their domain when explicitly requested by the user.

## Permission justifications

### tabs

Used after a user click or keyboard shortcut to read tab URLs, identify their
domains, remove stale grouping, and place matching tabs together in the current
window.

### tabGroups

Used to create, name, color, and expand the domain groups produced by the
extension.

## Privacy disclosure

No user data is collected or transmitted. Tab URLs are processed temporarily
and locally only to calculate domain groups.
