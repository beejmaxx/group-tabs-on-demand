# Changelog

All notable changes to this project will be documented here.

## 1.0.0 — 2026-08-16

- Initial public release.
- One-click and keyboard-triggered domain grouping.
- Mixed-domain group repair and stale singleton cleanup.
- Registrable-domain parsing with private suffix support.
- Short uppercase group labels and deterministic colors.
- Local-only processing with no analytics or remote services.
